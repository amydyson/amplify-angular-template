# Examples

This directory contains sample files demonstrating the PrinceXML integration.

## sample-output.html

This is an example of the HTML output generated by the PdfService. 

### How to Use

1. **View in Browser**: Open `sample-output.html` in any web browser to see how the content is formatted
2. **Print to PDF**: 
   - Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
   - Select "Save as PDF"
   - Enable "Background graphics" in print settings
   - Save the file

3. **Convert with PrinceXML CLI** (if installed):
   ```bash
   prince sample-output.html -o sample-report.pdf
   ```

### Features Demonstrated

- **Page Layout**: Letter size with 1-inch margins
- **Headers**: Document title appears at the top center of each page
- **Footers**: Page numbers appear at the bottom right (e.g., "Page 1 of 2")
- **Page Breaks**: Content is split across multiple pages using the `page-break` class
- **Tables**: Formatted data tables with styled headers
- **Typography**: Professional fonts and spacing optimized for print

### Note

Some advanced features like automatic page numbering in headers/footers require PrinceXML CLI or other PDF processors that fully support CSS Paged Media specifications. Browser print may not display all features.
